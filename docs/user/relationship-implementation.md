# 친구 및 차단 관계 구현 문서

작성일: 2026-08-14

## 친구 정책

현재 MVP의 친구 추가는 별도 수락 절차가 없는 즉시 양방향 관계다. 한 사용자가 친구를 추가하면 양쪽 마이페이지의 친구 목록에 모두 나타난다. 친구 해제 역시 어느 한쪽이 실행하면 양쪽 목록에서 제거된다.

## 친구 API

| Method | Endpoint | 기능 |
| --- | --- | --- |
| `GET` | `/api/users/me/friends` | 내 친구 목록과 친구 수 조회 기준 데이터 |
| `POST` | `/api/users/me/friends/{targetUserId}` | 친구 추가 |
| `DELETE` | `/api/users/me/friends/{targetUserId}` | 친구 관계 해제 |
| `GET` | `/api/users/me/blocks` | 내가 차단한 사용자 목록 |
| `DELETE` | `/api/users/me/blocks/{targetUserId}` | 차단 해제 |

## 친구와 차단의 상호작용

```text
친구 추가
  -> 자기 자신 여부 검증
  -> 양방향 차단 관계 검사
  -> 정렬된 사용자 ID로 중복 검사
  -> user_friends 저장

사용자 차단
  -> 기존 친구 관계 삭제
  -> user_blocks 저장
```

친구 관계가 대화 권한을 부여하지는 않는다. 채팅방 참여와 WebSocket 구독 권한은 기존 Room Member 검증을 그대로 사용한다.

## 프론트엔드

- 채팅 참여자 프로필 모달에서 친구 추가가 가능하다.
- 마이페이지 카드에 친구 수와 차단 수를 표시한다.
- 카드를 선택하면 해당 목록을 펼치고 친구 해제 또는 차단 해제를 수행한다.
- 해제 성공 시 서버 재조회 없이 목록과 카드 숫자를 즉시 갱신한다.
